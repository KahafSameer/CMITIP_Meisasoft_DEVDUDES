# CMITIP Meissasoft DevDudes: JavaScript & Node.js Practice

Daily JavaScript and Node.js exercises from the Meissasoft internship program.

## Contents

| Path | Topic |
|---|---|
| `first-program.js`, `array.js`, `objects.js`, `functions.js`, `conditions-loop.js` | JavaScript basics |
| `plan-day-3/` | Arrow functions, higher-order functions (`map`, `filter`, `reduce`), error handling, a shopping cart |
| `day4-plan/` | Tip calculator, temperature calculator, a HackerRank "candles" problem |
| `Day5-assesment/todoapp-witout-framwork.js` | Todo app without a framework |
| `core-modules.js`, `htttp-core-module.js`, `coreModules.txt` | Node.js core modules and the `http` module |
| `server.js` | Express server on port 3000 |
| `notes/` | Notes (Word document) |

## Run

```bash
git clone https://github.com/KahafSameer/CMITIP_Meisasoft_DEVDUDES.git
cd CMITIP_Meisasoft_DEVDUDES
npm install
npm start                 # node server.js → http://localhost:3000
node array.js             # run any single exercise
```
